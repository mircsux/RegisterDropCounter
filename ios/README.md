# Register Drop Counter for iPhone

Version **2.32.0** (2026-09-23). Designed by Ronald Robbins Jr and SuperGrok.

Native SwiftUI app. Same integer-cent drop as the Excel sheet and the Windows app.

- Yellow **Count** cells, number pad, Enter moves to the next denom.
- Till names default to **R1–R10**. Tap the name to rename.
- **Undo** brings back the last clear. **History** restores older snapshots.
- **Drop slip** prints or copies an 80 mm Star TSC100 receipt.
- Cash log rows copy as tab-separated values.
- Counts save on the phone. JSON files are visible in the Files app.

Open `RegisterDropCounter.xcodeproj` in Xcode. See HOW_TO_OPEN.txt.
