# Register Drop Counter for Android

Version **2.14.0** (2026-09-16). Designed by Ronald Robbins Jr and SuperGrok.

Kotlin + Jetpack Compose. Same integer-cent drop as the Excel sheet.

- Yellow **Count** cells, number pad, Enter moves to the next denom.
- Till names default to **R1–R10**. Tap the name to rename.
- **Undo** brings back the last clear. **History** restores older snapshots.
- **Drop slip** copies, shares, or prints an 80 mm Star TSC100 receipt.
- Cash log rows copy as tab-separated values.

Open this folder in Android Studio. See HOW_TO_OPEN.txt.
